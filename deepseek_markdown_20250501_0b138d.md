# 🚀 Шпаргалка по основным командам Git

## 🔧 Настройка Git
| Команда | Описание |
|---------|----------|
| `git config --global user.name "Ваше Имя"` | Установить имя пользователя |
| `git config --global user.email "ваш@email.com"` | Установить email пользователя |
| `git config --list` | Показать текущие настройки |

## 📂 Создание и клонирование репозиториев
| Команда | Описание |
|---------|----------|
| `git init` | Создать новый локальный репозиторий |
| `git clone <url-репозитория>` | Клонировать удалённый репозиторий |

## 🔄 Основные рабочие команды
| Команда | Описание |
|---------|----------|
| `git status` | Показать состояние файлов |
| `git add <файл>` | Добавить файл в индекс |
| `git add .` | Добавить все изменённые файлы |
| `git commit -m "Сообщение"` | Закоммитить изменения |
| `git commit -am "Сообщение"` | Добавить и закоммитить (только отслеживаемые файлы) |
| `git restore <файл>` | Отменить изменения в файле (до `git add`) |
| `git restore --staged <файл>` | Убрать файл из индекса |

## 🌿 Ветки (branches)
| Команда | Описание |
|---------|----------|
| `git branch` | Показать список веток |
| `git branch <имя-ветки>` | Создать новую ветку |
| `git checkout <имя-ветки>` | Переключиться на ветку |
| `git checkout -b <имя-ветки>` | Создать и переключиться |
| `git merge <имя-ветки>` | Влить ветку в текущую |
| `git branch -d <имя-ветки>` | Удалить ветку (если слита) |

## 📡 Работа с удалённым репозиторием
| Команда | Описание |
|---------|----------|
| `git remote add origin <url>` | Добавить удалённый репозиторий |
| `git push -u origin <ветка>` | Отправить изменения (в первый раз) |
| `git push` | Отправить изменения (после первого раза) |
| `git pull` | Получить изменения с удалённого репозитория |

## 🕵️ Просмотр истории
| Команда | Описание |
|---------|----------|
| `git log` | Показать историю коммитов |
| `git log --oneline` | Краткая история |
| `git diff` | Показать недобавленные изменения |

## 🚨 Отмена изменений
| Команда | Описание |
|---------|----------|
| `git reset --hard HEAD` | Отменить ВСЕ изменения (осторожно!) |
| `git revert <хэш-коммита>` | Отменить конкретный коммит |
